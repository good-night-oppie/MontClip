常见问题

MontClip 和 FableCut 是什么关系？

MontClip 基于 FableCut 修改，沿用 MIT 许可。FableCut 的完整功能见 上游 FableCut 文档；那些功能 MontClip 没有逐一验证。

中文能按单个字词剪吗？

现在还不能。中文听写目前只有整句的时间，可以按句剪。按字词剪还在验证。

需要登录或注册吗？

剪辑本身不需要。只有使用 AI 助手时，才需要你自己的 AI 服务账号。
