# 国内用户首次使用：语音模型本地就绪

2026-11-01，主人提醒国内主播可能无法访问海外模型，首次使用需要初始化本地语音模型。

## 首发决定

- Windows 完整便携包交付一个经中文实测合格的多语种语音模型以及 tokenizer、配置、运行库、WASM/worker 等全部必要文件。模型版本、资源清单、哈希和许可证绑定成品；具体模型仍以实测结果选择。
- 首次打开只做本地完整性检查、模型载入和必要的本地预热，不依赖 Hugging Face、jsDelivr、GitHub 或其他站点在线下载；界面区分正在检查、正在加载、已就绪及失败。不能把缓存命中当成随包离线能力。
- 初次模型加载可能耗时，显示实际状态并可取消/重试；不虚构进度或速度承诺。取消和失败不得破坏已有字幕与项目。
- 文件缺失或损坏时准确列明问题，允许选择经过哈希/版本验证的离线模型包或重新解压完整包。不静默转云端、不退回远端下载。
- 如以后提供精简包/独立模型包，必须显著标明需要另取模型；国内可达分发渠道实际验证后才能推荐，不预设任何镜像一定可用。不把改镜像域名当成离线交付。
- 本地听写与可选聊天模型分开：没有可用云模型时，导入、字幕编辑、手动剪辑和导出仍可用。海外云服务不能成为启动/本地听写门槛；聊天提供商可达性和数据外发单独验证，不宣称本地语音模型能承担剪辑聊天。

## 发布验收

1. 全新专用用户数据目录、无模型缓存，解压实际完整包；禁止外部网络仍可完成首次中文/英文听写。
2. 网络观察覆盖 Electron 页面/worker/Node 相关路径；只屏蔽海外域名不等于完全断网，配置关闭不等于没有请求。
3. 缺模型、坏哈希、缺 WASM、取消、重新加载分别验证；错误不触发自动外连，不丢项目。
4. 记录模型完整 revision、资源 hash、包体积、首次初始化耗时、首次推理耗时和峰值内存。准确率/词时间与离线能力分别报告。
5. 完整包的实际下载渠道也须国内可获得；缺国内实测条件明确写未验证，不能以本机海外网络成功代替。

本次是需求与交付决策，模型尚未实测、未打包，不宣称门槛已通过。
