# MontClip 首发：中文优先、中英双语

状态：主人明确要求，2026-11-01；尚未实现或验收。

## 发布目标

首发日期为 2026-11-03。主人未指定发布时刻或时区，不擅自补成某个时区的 23:59。此日期替代旧 JJ-Agent 的历史发布日期。

面向中文用户，第一版同时提供简体中文与英文。采用同一 App 内切换语言的实现方向，不维护两套分叉产品。首次启动默认简体中文，用户选定后本地保存；再次启动保持选择。

## 实现边界

- 在 FableCut 代码上实现国际化；遵守无 Python 侧车的决定。
- 界面固定文字通过稳定键读取 zh-CN/en 资源；不批量替换代码字符串或用户素材文字。
- 覆盖首开、导入、编辑、字幕选择、保存、撤销、导出、设置、退出和失败提示，以及工具提示、无障碍名称、主进程原生对话框、随包使用说明。
- 不翻译用户录像名称、转录原文、字幕、项目名称或用户填写内容。界面语言与听写语言分开。
- 错误使用稳定错误码与参数映射到当前语言，技术详情可保留原文；不把原始英文异常作为中文用户唯一可见提示。
- 法定许可证及版权原文保留；中文说明不替代原许可。
- 字体来源、许可和中文字形覆盖须核验；中英两种长度下检查布局、换行、截断及按钮可见性。

## 首发验收

1. 新数据目录首开为简体中文；切换英文、退出重开仍为英文；切回中文有效。
2. 两种语言各完成录像/SRT 导入、选段、撤销重做、保存重开、导出与打开导出目录。
3. 两套资源键一致、占位参数一致、缺键检查通过；核心界面无未翻译的上游英文文案。
4. 保存失败、缺媒体、编码不支持、导出失败和退出确认在两种语言下均有可执行的下一步。
5. 中文标题、中文字幕、标点和中英混排，在预览和导出中无方框、丢字或布局溢出。
6. 中文流程优先完成 JJ 文案复核与 VV 真窗口体验；英文同版检查，不延至第二版。
