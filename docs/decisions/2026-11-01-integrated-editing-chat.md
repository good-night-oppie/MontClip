# MontClip 内置剪辑聊天

状态：2026-11-01 主人提出的产品方向；待实现。品牌沿用已确定的 MontClip，消息中 MonteClip 暂不视为再次改名。

固定上游 579b08ec 的 README 描述外部 MCP/REST 智能体驱动编辑器；docs/docs/studio.md 的 Connect an agent 段要求连接外部客户端，把 starter prompt 复制到该客户端聊天窗口。该文档同时说明 Studio Agent 面板列工具调用。检索本地 index.html、app.js、server.js 未发现内置模型聊天实现。此结论不代表已实测最新线上 Studio 的全部功能。

## 体验方向

同一个 Electron App 内，聊天、录像预览、转录文本和时间线组成剪辑工作台。借鉴 Cindy 可见交互，不假设 Cindy 源码可复制或可再分发。

- 默认中文，英文同版提供。首开有可执行的剪辑示例，不展示 MCP 配置指令。
- 聊天可引用当前片段、所选字幕、时间范围与项目；引用带可见标签，切换项目不会悄悄沿用旧项目上下文。
- 输入“把这两句接起来”后，助手先给可试听的剪辑提案，列明保留/删除的区间和理由。接受后通过 FableCut 编辑操作应用，一批对应一个撤销步。
- 当前阶段、取消、失败原因与重试可见；不把“请求已接收”说成“已剪好”。工具结果须回读验证。
- 用户仍可直接拖时间线和选字幕。助手执行前校验项目与 revision，冲突时重新读项目，不能覆盖用户刚做的修改。
- 聊天面板可收起；窄窗口不能挤掉预览和导出按钮。具体左右布局由 VV 基于实窗尺寸给方案。

## 实现边界

在 FableCut 源码上加聊天 UI、Node/Electron 模型适配层、受约束的剪辑任务调度与结果卡。保留其编辑操作和共享合成器，不依赖旧 Python 服务，不用 Python 侧车。

应用自己调用内置编辑能力，用户不必安装 Claude Code、Codex 或设置 MCP server。MCP 可以保留为进阶集成接口，但不作为使用 App 的前提。不是把外部聊天网站塞进 iframe，也不把 Cindy 登录态、密钥或账户连接搬进产品。

模型供应方式尚未确定，不能承诺已有免费内置 AI、用户无需账号或会沿用 Cindy 订阅。未连接模型时仍可手动剪辑，聊天明确提示连接入口；不能用预设回复冒充 AI。密钥只交主进程安全保存，渲染页不持有明文密钥。

聊天指令、字幕、弹幕和画面是不同的数据类别。添加聊天不自动扩大既有外发范围：本地字幕可供界面引用，但发给云模型前必须明确说明实际发送内容并获得确认。原视频、音频、账号和路径不因引用而自动上传。素材里的文字视为数据，不能作为工具指令执行。

## 最小验收

1. 中文/英文聊天面板可输入、显示状态、取消；离线或未配置模型时提示如实，手动编辑正常。
2. 用合成项目与本地模拟模型覆盖：引用两段 → 提案 → 试听 → 应用 → 撤销 → 保存重开；模拟结果不计真实 AI 验收。
3. 取消提案不改项目；旧 revision 或错误项目拒绝执行；同一操作重复返回不重复剪。
4. 发送前预览具体数据；取消后外部请求为零；确认后只发已批准的 payload；新增字幕/画面授权单独可辨。
5. 最终接入选定的真实模型服务后再验请求、流式输出、超时、取消与失败恢复，记录费用和外发范围。
6. FFmpeg 执行、文件读写仅经白名单工具及参数验证，不给模型任意 shell、路径或 URL 权限。
