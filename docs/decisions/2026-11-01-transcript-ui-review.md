# 转录界面 v1 评审

日期：2026-11-01。结论：默认布局方向接受，细节要改；不是产品验收通过。

证据：已读 VV《转录编辑器界面说明-VV-v1.md》，看过 T1-1093x534-light.png；未运行可点击稿，未复跑其32项测试，未检查全部截图。VV数字仅代表其合成界面稿。

## 决定

1. 不批准整层删除 FableCut UI、只留所谓引擎。其 app.js 的界面与合成/编辑耦合，先通过适配层逐步重排与简化，保留原有操作语义及共享合成路径。默认展示转录、预览、简化时间线；提供可展开的高级时间线，操作同一个项目，避免两套撤销/保存。不是首页暴露全部专业按钮。
2. T1b“整场选文字做切片”为必需功能。SRT 支持按字幕段选；逐词操作须有实际词时间。多段选择显示将拼接的各段及间隙处理，不默默包含全部中间内容。
3. 加入可收起的内置聊天面板，与当前字幕/选段引用联动。窄窗采用转录/聊天切换或覆盖侧栏，保持预览、播放、导出可达。双语从首版覆盖，中文优先。
4. 接受保存状态固定占位、不吞连点、预览成品一致、弹层按钮不被迟到内容推移、写入失败可换导出文件夹。换目录不得丢项目或清除失败信息，成功回读才显示已导出。

## 必改文案和行为

- 导出标准 SRT 只含成片字幕时间；原片到成片的映射放独立 JSON，不能宣称 SRT 自带双时间字段。
- 改字为空时可取消或提供明确“仅隐藏这条字幕”的操作，不引导点会同时删除音视频的“删掉”。删视频、改字幕、隐藏字幕分别表达。
- “返回不确认，已保存”只适用于已收到保存成功回执。保存中/失败/结果未知要保留修改和重试途径；没有自动重试就不能显示“重试中”。
- 本地听写、进度百分比和预计时间须对应真实实现。有模型才显示可用；不能以设计稿承诺离线听写已完成。无 Python。
- ±1帧仅在可确定帧边界时启用；不确定时明确显示按时间调整及步长，不能保留“1帧”标签却移动0.5秒。
- 停顿保留0.15秒及三档力度是试验参数，不是已验证标准。歌舞与类型不确定片段默认不批量清理，不能假设已有可靠音乐识别。
- B站遮挡区尚未实测，标为参考安全区，不写成已知平台按钮位置。画面放法、字体、高亮规则必须走同一预览/导出合成定义，不强制另建ASS渲染链。
- 剪映适配尚未验证，不呈现可用的导出选项，也不把“必须先关剪映”当已核事实；OTIO同样须实际读回通过后再宣布可用。
- 840宽下下拉文字截断须修复，英文长度与中文字体均进入布局测试。

## v1 同路径更新：补充核对

已核说明新增“二点五”节：停顿高亮、删句、收起时间线、上一句/下一句、白底黑字标题。删句菜单与上一句/下一句明确为 VV 推断或独立设计，不登记成 Opus 已验证行为。

这些可纳入交互设计；删句必须明确音视频联动删除且一步可撤销，上一句/下一句需按当前可播放序列定位，收起时间线不丢选区和播放位置。标题样式作为预设，不锁死用户样式。

“首版不做手动裁切/加图片/链接与音量工具”视为简化界面的建议，不批准删除 FableCut 既有能力或从原需求表移除。默认页面可隐藏复杂工具，已验证功能通过高级界面保留；未经验证的功能如实标记。显式保存按钮可不常驻，但保存状态、失败重试和未保存退出保护必须可达。

## 三句文案复核

结论：两处同意、一处要改；整稿尚未定稿。

- 同意标准 SRT + 独立时间对照表的说明。导出是否有字幕文件取决于实际存在的字幕，不能在无字幕项目中承诺有有效 SRT。
- 同意清理力度用白话描述，以及“留一点气口”。0.81秒只有来自实际检测时才能当测量结果；原型是合成占位。0.3秒显示筛选可以保留，明确不自动删除。
- 听写失败需按真实原因分支，不能所有失败都说文件没找到。只有确定包内应附带的文件缺失时，才建议重新完整解压 MontClip；若是未配置模型，则给实际本地模型选择入口；未知原因保留重试和可用详情。“切片助手”统一改为 MontClip。原片和选段不变的承诺需失败路径测试支持。
- 说明开头仍写“界面整层换掉，只留引擎”及“高级入口待定”，与已作决定冲突，需同步删除旧结论。专业时间线默认收起，可从高级入口展开，仍用同一项目。
