# ADR-003：CapCut 9.4.0.4015 导出适配范围更新

日期：2026-11-01。状态：主人已决定目标；实现及兼容性待验收。

主人原话：「剪映、CapCut版本号，就按本机 CapCut version 9.4.0.4015」。

## 决定与历史边界

本 ADR 是 MontClip 的新决定，替代旧项目「不集成 CapCut」对本次导出适配范围的限制；不改写旧项目历史结论。MontClip 原树此前没有 ADR-003 文件。目标固定为本机 Windows CapCut 9.4.0.4015，不再等剪映专业版版本，也不另外安排剪映一轮。

范围只限用户发起导出时的适配输出。不是双向同步、自动读取现有项目或控制账号发布。MP4、剪后 SRT、独立时间映射和 OTIO 继续开发验证；不能因版本指定就宣称草稿已兼容。

## 前置研究及隔离

Rea 的研究排在 M2 后段、M3 适配实现之前；现有安装和独占桌面时段核实后可提前开展。Cindy 与 VV 协调时段，不抢正在使用的桌面。版本由 Rea 从本机 exe 核对；若与指定值不符，报告差异而非升级、换版本或继续假定。

只用原创合成素材、全新专用测试草稿，不读用户旧项目、不借用用户草稿种子、不解密。既有 SPEC 的准入结论不自动覆盖外部新草稿写入。实现侧仅收纯外部行为 SPEC.md，独立实现；不接收反编译原件或内部代码。

SPEC 要交代外部生成新草稿是否接受、最小可观察输入输出、登记是否必要、运行中/关闭状态差异、字幕导入类型、保存前后 hash、网络观察边界、错误和恢复。失败可以是有效研究结果，不能编造兼容。

## 验收

新合成项目由适配输出导入指定版本，确认媒体/字幕/片段顺序与时间，保存重开；与 MontClip 导出时间映射核对。QQ 审具体提交，VV/Rea 提供具体客户端版本和可复现证据。未完成时不展示为已支持，其他导出路径不因此停止。

本次仅文档，未运行 CapCut、未核 exe、未做产品测试。
