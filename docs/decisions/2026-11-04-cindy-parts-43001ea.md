## What is taken

Nine Cindy components, unchanged, in `agent-ui/cindy-43001ea/` (Cindy's own folder layout, so their imports work as in Cindy):

| Part | Used for (v7.2) |
|---|---|
| PermissionSelector | the mode capsule 〔手动 ▾〕 |
| JumpToBottomChip | 「↓ 回到最新」 |
| InlineReferenceChip | the quoted captions in your message |
| TodoListCard | the plan list (待做 / 进行中 / 完成 / 没做成) |

| AskUserQuestionPrompt | the question card |

`agent-ui/vendor-cindy.cjs <checkout>` copies them: it bundles the entry points with the same resolver as the build
(`agent-ui/cindy-resolve.cjs`) and copies every Cindy file that bundle reads, 145 files with LICENSE, NOTICE and
`packages/maker-shared/package.json`. `SOURCES.json` (`parts`) records each file's git blob and sha256;
`test/cindy-parts.test.js` checks them and that no other file is there. The LICENSE and NOTICE are the same as at
`0219236`, where the first components (composer, send button, text field) come from.

## Built, not only analysed

Deja's check (`deps.cjs`) followed imports statically. Bundled for real at 43001ea:

- ErrorMessageCard, WorkGroupBlock, ToolCallCard and AskUserQuestionPrompt built once the stand-ins below took the

  - `basename` from `@/lib/utils` (Cindy's own `lib/utils` is now used as it is, with clsx and tailwind-merge).

  (`window.electronAPI.maker`, through `hooks/useAgentCapabilities`). Without it the menu is empty, so a stand-in gives
  MontClip's four modes.

## Strings

The parts use i18next as Cindy does (namespace `common`, English fallback). Cindy's whole common.json is 2 MB per
language, so `vendor-cindy.cjs` keeps the strings these files can ask for (`cindy-strings.json`, 343 zh-CN / 352 en;
the 9 more in English are `_one` plural forms). It reads the string literals with TypeScript's parser: a regex
mispaired quotes and missed keys. `montclip-strings.json` holds MontClip's words where Cindy's do not fit; for now only
the mode capsule (the four modes, as in the pane today). The smoke checks that no part asks for a missing key.

## The bundle

The parts are in `cindy-official.js`, as `window.MontClipCindyParts`; the pane does not show them yet. The bundle grows
from 221 KB to 608 KB. Every npm package in it is listed in `BUNDLED-PACKAGES.json` (written by the build), with its
version and full license in `BUNDLED-LICENSES.json` and `THIRD-PARTY-NOTICES.txt` (written by `licenses.cjs`).
react-remove-scroll-bar 2.3.8 ships no license file: its MIT text comes from its repository (commit recorded).
