MontClip {version} 内部试用版

这是试验版本，只给内部试用，可能会出错。你的原录像不会被改动。

【打开】
1. 先核对文件：下载页上的 SHA256SUMS.txt 写着这个 zip 的 sha256。把你下载的 zip 算出来的值和它对一下，对不上就别用，找发包的人。不会算的话，也直接问发包的人。
2. 把整个 zip 解压到一个你能写入的文件夹，比如「文档」里新建的一个文件夹。别直接在压缩包里双击运行。
3. 双击 {exe}。
4. 这个版本还没有数字签名，Windows 可能会弹出「Windows 已保护你的电脑」。只要上面第 1 步的 sha256 对得上，就点「更多信息」→「仍要运行」。对不上就别点。

【现在能做的】
- 导入电脑里的录像（建议先用 MP4）。
- 导入现成的 SRT 字幕，然后按句勾选想留的部分。先试听，再应用，一步就能撤销。
- 「高光候选」：在本机根据声音和字幕列出几段可能好看的片段，供你挑。它只是候选，不调用 AI，也不会替你剪；留哪段由你自己勾。
- 导出 MP4 和 SRT 字幕。每次导出都会弹出 Windows 的保存窗口：导出视频一次，导出字幕再一次。窗口默认在「下载」文件夹，选好位置再点「保存」。
- 可选的 AI 助手：要连接你自己的 OpenAI 或 DeepSeek 账号，费用记在你的账号上。不连接也能正常剪辑。

【这一版还不能做的】
- 不能在本机听写中文。需要你先准备好 SRT 字幕文件。
- 只能按整句剪，不能按单个字剪。
- 部分界面和提示还是英文。
- 还不能导入弹幕，所以「高光候选」暂时只看声音和字幕。
- 「+ 网址」（从网址导入）这一版用不了，会提示「当前为离线模式」。请导入电脑里的文件。
- 只在 Windows 11 上测试过。

【导出视频要注意】
导出 H.264（普通 MP4）时，用的是你电脑的显卡编码器或 Windows 自带的编码器，不用另外装任何东西。
- 如果提示「找不到能用的 H.264 编码器」：多半是显卡驱动问题，或者你的 Windows 是不带媒体组件的「N 版」。N 版请在 Windows 设置 › 应用 › 可选功能里安装「媒体功能包」，然后重新打开 MontClip。
- 想要画质更好，可以在设置里选一个你电脑上自带 x264 的 FFmpeg。这是可选的，不选也能正常导出。
- 每次导出，软件还会在电脑里另外留一份副本，会占 C 盘空间（下个版本会改掉）。你自己选位置保存的那份不受影响。C 盘紧张时可以手动删掉副本：先关掉 MontClip，打开任意一个文件夹，在上面的地址栏里输入 %APPDATA%\MontClip\workspace\exports ，按回车，删掉里面的视频文件。只删 exports 这个文件夹里的东西，不要删 workspace 里别的文件夹或文件，那里有你的项目，删了会丢。

【联网】
- 只有 AI 助手会联网，而且要你自己点发送并确认才会联网。
- AI 助手只发你在核对框里看到的文字，不发录像、音频、截图、项目文件。
- 不想再用 AI 助手：在「助手 › AI 服务」里点「删除这个连接」，这台电脑上保存的密钥会被清掉。
- 详细说明见发布页上的「发布说明」。

【遇到问题】
- 卡住时，先照界面上的提示做。
- 反馈时请告诉我们：第几步、你点了什么、屏幕上写了什么（截图前请把昵称、账号、文件路径打码）。
- 录像和弹幕只留在你的电脑上，不要发给我们。
